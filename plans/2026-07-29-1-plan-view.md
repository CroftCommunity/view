# Plan — View (view.croft.ing), 2026-07-29

> **Superseded — historical record.** This document reflects the original build,
> which planned two decisions later revised. View is now a **discovery portal**
> that streams/embeds third-party media *in place*, not a mirror: (1) Parks
> streams the NPS `.mp4` directly and Live embeds the explore.org player (served
> on YouTube), so **`mediaBase`/R2 is only for our own future (Mine) content**;
> and (2) **constraint C1 ("no YouTube embeds, ever") is reversed** — the embed
> was chosen over an external link, accepting the source player's ad tradeoff.
> History below is kept intact; for current behaviour see `README.md`,
> `docs/DEPLOY.md`, `docs/SECURITY.md`, and `docs/CONVENTIONS.md`.

## Problem statement

Build "View — a window from another point of view": ambient scenery views for any
screen, kiosk-friendly for a wall display, static-only, deployable to
`view.croft.ing`. Content is a few carefully-licensed sources with the licence
shown per scene. Hard constraints: **C1** no ads ever → no YouTube iframes
anywhere; **C2** per-scene licensing rendered on-page; **C3** `npm run test` green
at the end of every phase; **C4** code is AGPL-3.0, scene content licences are
separate and per-shelf.

## Approach

Transplant the `CroftCommunity/croft-pwa` chassis (its own "starting a new Croft
PWA" instructions) and build View's content system on top: a root `scenes.json`
(the only place content lives), a stage renderer (video/embed/link) with a
per-scene credit chip, three shelves (Live · Parks · Mine), and a kiosk mode. Keep
`mediaBase` as the single deploy-time switch.

## Reasoning / locked decisions

- **Chassis verbatim where possible** (theme, log, version, sw-register,
  update-toast, the whole `measure/` telemetry module, config). Adapt `build.mjs`
  (pages, scenes.json validation + C1 build gate, CSP origins derived from
  scenes.json) and `nav.ts` (tabs, wordmark, footer licence line).
- **C1 in three layers:** a runtime validator, a unit test scanning the shipped
  `scenes.json`, and a hard build-time assertion — all rejecting YouTube embed
  hosts.
- **Live = `link` cards, not embeds.** The per-cam first-party audit cannot be
  performed in this hermetic environment, and C1 admits no third option, so all
  Live cams ship as link cards (poster + "Watch live at explore.org →"). The
  `embed` path is implemented and unit-tested but not activated, so the CSP stays
  tight. (RUN-P4 records this.)
- **Parks = `kind:"video"` relative under `mediaBase`.** NPS no longer exposes
  direct `.mp4` (only first-party embed players), and the "no NPS arrowhead
  anywhere in the app" rule argues against embedding NPS player chrome. So Parks
  references `media/parks/*.mp4` (the R2-mirror target), keeping the mediaBase
  design uniform and the app free of third-party chrome. Real NPS clip pages are
  the credit links; embed IDs are recorded for the owner's mirror step.
- **Default home shelf = first non-empty (Live).** No eager remote load on paint
  (link cards + tap-to-play video), so the hermetic gate — csp/a11y/mobile/subpath
  — stays green with a tight CSP.
- **Token names:** express View's two-weather palette through the chassis semantic
  roles (so `brand-tokens.test.ts` holds); poetic names live as comments +
  `docs/CONVENTIONS.md`.
- **Deploy reality:** `view.croft.ing` is on GitHub Pages (owner-configured), not
  R2. App → Pages (CNAME + Actions deploy); video → R2 via `mediaBase`.

## RED → GREEN order

Per phase: write/adjust the unit + e2e tests, watch them fail, implement, gate
green, write `RUN-P<n>-SUMMARY.md`, commit.

1. P1 chassis transplant + empty shells → gate green.
2. P2 catalog system (scenes.json, loader/validation, stage, credit, C1 scan).
3. P3 brand tokens (morning air / comforting storm) + window signature + copy.
4. P4 shelves (Live/Parks/Mine) + kiosk + kiosk e2e.
5. P5 legal furniture (about legend, footer, contact, AGPL), offline page, PWA/a11y
   checks, full gate + push.

## Not in this run

- Standing up a real telemetry receiver (posture is log-only, per croft-pwa).
- R2 upload + `mediaBase` flip (owner task; code is compatible and tested).
- Activating the `embed` kind / per-cam explore.org first-party audit (needs a
  non-hermetic audit; C1-safe link cards ship instead).
- Solar-time auto theme (left as an OFF-by-default idea, not built).
